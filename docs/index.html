02 / Principles

How I work

The rules I hold myself to on every build, from first sketch to launch.

  1. 01 · AI

    AI-First Thinking

    I don't bolt a model onto a finished app. I start by asking what an agent should run, what a human should decide, and how we'll know it worked.

  2. 02 · USER

    User Perspective

    I start from the person who has to use it. If the click, the wait, or the error doesn't make sense to them, the rest of the stack doesn't matter.

  3. 03 · HANDS

    Still in the Code

    A title doesn't move me off the keyboard. I lead by writing the system, including the agents, the full stack, and the path that has to work.

  4. 04 · FINISH

    Own It Through Launch

    I stay on the problem until someone can use it. Sketch to shipped. No throwing the hard parts over a wall.
